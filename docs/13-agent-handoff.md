## 3. 研究思路及其原因

研究问题：在相同数据划分和标准二维U-Net下，损失函数与适度训练增强怎样影响乳腺超声病灶分割？研究价值在于条件明确的对照、病例层面的统计解释和完整可复核流程，不预设结构创新或性能提升。

| 已选设计 | 具体约定与原因 |
| --- | --- |
| 数据与任务 | 只用BrEaST主实验，tumor为目标，other不合并；分割不等于良恶性诊断 |
| 模型输入 | 256×256单通道灰度图；病例表不作为预测输入，真实标注不用于测试时定位或裁剪 |
| 患者划分 | 主病灶队列按良恶性分层60/20/20，种子20261013，所有组共用；病例数须以最终纳入和划分程序为准 |
| 四组设计 | A=BCE/无增强，B=0.5BCE+0.5Dice/无增强，C=BCE/有增强，D=联合损失/有增强 |
| 重复训练 | 每组种子17、42、2026，共计划12次；种子不是病例号，也不是新增患者 |
| 网络与训练 | TensorFlow/Keras标准2D U-Net，通道32/64/128/256/512；Adam 0.001、batch 8、最多100轮；验证软Dice早停，patience 15、min_delta 0.0001；均待环境验证和协议冻结 |
| 增强 | 仅训练集，以0.5概率同步旋转±10°、平移±5%；不用翻转或强形变；目标完全移出时回退原图并记录 |
| 阈值 | 每个组/种子分别在验证集按病例平均硬Dice选择，候选0.10到0.90、步长0.05；并列先靠近0.50再取较大者；另报固定0.50辅助结果 |
| 主要比较 | D−A，评价训练方案配合统一验证选择程序后的差异；其他比较为次要探索，D−A不能单独证明两个因素都有效 |
| 独立统计单位 | 病例；逐病例分别计算Dice和IoU，再对同病例三个种子的指标取平均，不平均概率图，不称为模型集成 |
| 不确定性 | 患者配对Bootstrap 5000次，95%百分位区间；条件于当前划分、已训练模型及阈值，不涵盖全部训练随机性或外部泛化 |
| 病例探索 | 原图病灶面积占比，训练集真值确定三分位切点；Margin可能多标签；这些不是物理尺寸、临床分期或图像模糊程度 |
| 选图 | D组病例的种子平均Dice用于预设排序，各组展示同一病例、固定种子17的轮廓；案例解释不代替总体统计 |
| 正常病例 | 4例单独探索误检，不进入主训练、验证和主分割均值；采用对应运行的验证阈值，不据此再次调阈值 |

普通软Dice损失与文献中的广义Dice、Unified Focal Loss不同，不宣称完整复现后两者。评价空掩码规则、损失归约及其他细节以配置和统计协议为准。不得因为测试结果差而更换划分、挑选种子或剔除困难病例。

## 7. 讲解进度与下一步验收

已用中文逐节讲解开题1.1、1.2、1.3、2.1、2.2、2.3，另解释过散斑噪声。用户请求“下一部分”时从 **3.1 数据来源与患者划分**开始：解释官方256病例、本地清点与最终纳入的区别、正常病例单列、60/20/20分层患者划分及种子含义。每次讲一节，引用少量实际原文，术语配通俗解释；假设数字明确标注为例子。理解进度不等于研究实施进度。

推进研究的下一项验收是人工技术复核及纳入决定：恢复原图、审计和图册，核对记录与当前文件一致；逐项记录疑问、依据、处理及实际复核者，不替用户或临床专家签署。边缘目标暂建议保留并说明视野限制，不自行修边或剔除。之后才生成固定患者划分、检查集合交集并保存清单及哈希。

再之后：验证独立TensorFlow环境 → 实现同步增强、网络、损失和训练 → 用训练/验证集进行小规模正确性检查 → 冻结协议 → 12次正式训练 → 锁定阈值后评价测试集 → 配对统计与论文结果。各阶段具体验收见[执行路线](09-guided-thesis-roadmap.md)与[实现流程](04-implementation-workflow.md)。

若当前只继续写作，可完善已有背景和方法、阅读文献及解释原稿；没有真实实验时，结果章节保留待完成状态，不编造数字、图像或结论。
