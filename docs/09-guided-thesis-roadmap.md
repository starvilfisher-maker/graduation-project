# 论文执行与学习路线

从已有研究方案进入真实实施。每次完成一个可验收的小阶段，并解释产物如何写进论文。本路线没有时间安排。技术细节见[实现流程](04-implementation-workflow.md)，数据规则见[数据协议](02-data-protocol.md)，统计规则见[实验协议](03-experiment-and-statistics.md)。实际完成情况只以[交付记录](08-delivery-status.md)为准。

## 先明确论文要回答什么

研究问题：在同一批乳腺超声病例、同一 U-Net 结构和同一评价规则下，改变损失函数、使用适度数据增强，病灶区域的分割准确性和训练稳定性会怎样变化？对较小病灶和不同边缘特征的病例，表现是否有所不同？

输入是一张超声图，输出是同样大小的病灶概率图。概率经过事先选定的阈值变成二值预测掩码，再与专家目标标注比较。这里的“肿瘤”包括良性目标；本课题不训练良恶性分类器。

应用统计学的贡献包括：设计公平对照、避免患者泄漏、区分不同波动来源、给出差异及不确定性、解释病例之间的表现差异。论文是否成立不取决于改进方案一定超过基线；规范且可解释的无改善结果也应据实报告。

| 方案 | 用什么标准指导模型学习 | 是否使用训练增强 |
| --- | --- | --- |
| A | BCE：逐像素衡量预测与答案的差异 | 否 |
| B | 0.5 BCE + 0.5 Dice loss：兼顾逐像素差异和整体重合 | 否 |
| C | BCE | 是 |
| D | 0.5 BCE + 0.5 Dice loss | 是 |

每组使用种子17、42、2026，计划12次正式训练，所有运行共用患者划分。种子改变初始化和训练随机过程，不会增加独立患者人数。主要比较D与A的组合策略差异；单独讨论损失或增强的作用还需结合其他对照。

## 从开始到交付的十步

| 步骤 | 本步具体做什么 | 完成后必须拿到什么 | 可以写入论文哪里 |
| --- | --- | --- | --- |
| 1. 确定问题与论文框架 | 说明输入、输出、研究人群和四组比较；建立章节提纲 | 一页研究说明、实验组表、论文目录 | 绪论、研究设计 |
| 2. 学会必要概念并读文献 | 先理解病灶、超声、掩码、分割；先读数据说明与U-Net原文，再读损失、增强、评价文献 | 术语笔记、逐篇证据表、核实过的引用 | 绪论、理论基础与相关研究 |
| 3. 获取和核对数据 | 下载官方文件、保存来源和哈希；按病例表匹配图像与两类标注；自动检查并人工浏览 | 病例清单、文件清单、异常记录、核对图与人工复核记录 | 数据来源、纳入标准、质量控制 |
| 4. 固定患者划分 | 完成质检后按患者分训练/验证/测试；按良恶性分层；正常病例单列；检查交叉与重复 | 固定患者名单、各集构成表、交集检查、划分哈希 | 实验设计 |
| 5. 实现预处理与增强 | 256×256、归一化；图像双线性、掩码最近邻；训练图和掩码同步旋转/平移 | 可运行数据管道、预处理与增强对照图、边界测试 | 数据处理方法 |
| 6. 搭建U-Net并试跑 | 建立独立TensorFlow环境；核查设备；实现模型和损失；仅用训练数据调试，验证集辅助选择；正式实验前冻结参数 | 模型结构与参数量、环境记录、小规模试跑、冻结协议 | 模型原理、训练设置 |
| 7. 完成正式训练 | 四组各三个种子；每次重新初始化；用相同验证规则早停；保存全部运行 | 12套日志、曲线、配置、模型和可追溯版本 | 实验设置、训练结果 |
| 8. 选阈值并统一测试 | 每个模型只用验证集选阈值，冻结后在测试病例评分；正常病例独立评价误检 | 阈值记录、逐病例Dice/IoU、预测轮廓、正常病例误检表 | 实验结果 |
| 9. 完成统计与失败分析 | 分别描述病例差异和种子波动；按患者配对Bootstrap；分析相对大小、边缘标签、漏分和过分 | 结果表、差异区间、分组图表、失败案例解释 | 结果、讨论 |
| 10. 定稿与复核 | 方法对应实际代码，结论对应实际结果；复核文献、公式和图表；按正式论文要求排版 | 论文、程序、环境说明、实验记录、答辩材料 | 全文与附录 |

第2步会持续补充，不要求读完所有文献才下载数据。每完成一个阶段就积累相关正文：数据阶段写数据来源，模型阶段写方法；结果和结论等待正式实验。当前学校Word模板适用于开题报告，正式论文排版要求仍需另行核对。

## 数据入门与当前推进位置

下文保留入门概念及起步记录。当前已完成数据的确定性解码、全量缩放检查、图册和本地开题材料；下一项验收是完成逐例人工复核记录与最终纳入说明，再进入固定患者划分。不能因为开题稿和文献包完成就跳过数据验收。

| 术语 | 在本课题中的具体含义 | 容易混淆的地方 |
| --- | --- | --- |
| 超声图像 | 输入模型的二维像素阵列，展示组织对超声信号的响应 | 灰暗区域不自动等于病灶，不能仅靠亮暗判断 |
| 病灶 | 本研究希望圈出的目标异常区域 | 病灶或tumor不等于已经确诊恶性癌症 |
| 掩码（mask） | 与原图位置对应的二值标签图，1表示目标区域，0表示目标以外 | 白色是标签显示方式，不表示病灶实际呈白色 |
| 分割 | 给每个像素判断是否属于目标，最终形成区域与轮廓 | 不等于给整张图判断良性或恶性 |
| tumor标注 | 当前要学习的目标病灶参考区域 | 训练和评价使用它，但推理输入不能包含它 |
| other标注 | 数据集中另外标出的可疑区域 | 本课题不自动将其合并到目标掩码 |
| 正常病例 | 由病例表及说明确认没有目标病灶的病例 | 缺少标注文件本身不能证明正常 |

可以把原图理解为一道题，把专家掩码理解为参考答案。训练时模型用答案纠正参数；测试时模型只读原图，预测完成后才由评价程序拿答案评分。病例表用于关联和分组，不能随意作为模型额外输入。

### 已执行的起步操作

2026年10月14日从[TCIA官方页面](https://www.cancerimagingarchive.net/collection/breast-lesions-usg/)下载Version 1的图像/标注压缩包和病例表，保留原始文件；本地保存来源页、下载来源、时间、大小和SHA-256，ZIP完整性检查通过。哈希由本地计算，用于后续追踪文件变化，不表示已与发布者校验值比对。

病例表初步读取为256行、21列，分类计数为良性154、恶性98、正常4。这是实际文件清点结果，不是已经通过全部质检的最终研究样本量。实际首表的编号字段为`CaseID`，数据字典用`Case_ID`描述；按实际表头解析，记录该差异。完整审计是否通过见交付记录。

资料保存在本地`data/raw/BrEaST-v1/`，来源记录保存在`data/audit/source_records/`。原始数据和病例明细不随代码公开上传。

### 怎样读三联示例图

1. 左图是模型未来会看到的超声原图。
2. 中图是专家目标掩码；白色为目标，黑色为目标以外区域。
3. 右图把目标轮廓叠加在原图上，帮助检查二者是否对齐。

三联图中的轮廓来自已有专家标注，**不是U-Net预测**。此时尚无任何模型分割成绩。示例仅用于理解数据，不代表全部病例已人工复核。

### 数据阶段结束前的验收

- 病例编号和图像路径唯一，每份标注能按病例表明确对应；异常不会被静默跳过。
- 区分正常病例、病灶病例缺标注、目标空掩码，以及其他结构标注。
- 核对图像和掩码尺寸、像素值、通道及透明度；检查内容重复。
- 对全部病例浏览叠加图，并记录人工复查结论；自动检查通过不能替代这一步。
- 检查256×256最近邻缩放后目标是否消失。异常先调查和记录，再决定是否纳入。
- 完成上述核对后才能正式确定样本数并生成固定患者划分。

## 每次怎样一起推进

后续每轮沿用四项结构：说明本次目的；执行并展示可检查产物；解释结果及限制；给出与实际工作一致的论文写作要点。你主要需要理解研究选择、查看关键图表和确认学校要求；重复性文件整理、代码实现和检查可以由助手完成。

理解第一课后，应能用自己的话说明：模型输入什么、预测什么，掩码为何是参考答案，为什么一例患者的多次预测不能当作多个独立样本。接下来继续完成数据的逐例可视化复核，再进入患者划分。
