# 《基于 U-Net 的乳腺超声病灶分割研究》课题分析

> 文件性质：研究设计说明，供理解课题、讨论方案和撰写开题报告使用，不是已经完成的开题正文或实验报告。本文的比较结果均为待验证问题，未开展真实数据训练，也不包含实验成绩。

本文用于解释研究思路；具体纳入、划分、参数和统计规则统一以[数据协议](02-data-protocol.md)和[实验协议](03-experiment-and-statistics.md)为准。它们目前也是拟采用的方案，需要在正式实验前核验并冻结。

## 1. 这项研究究竟要完成什么

本课题建立一个从乳腺超声图像到病灶区域的自动分割流程，并回答：在相同数据划分和标准 U-Net 结构下，损失函数与数据增强是否影响分割质量、训练稳定性以及不同病例的表现。

输入是一张二维超声图像，输出是与图像位置对应的病灶概率图。将概率图按预先确定的阈值转为二值图后，与专家提供的标注比较。例如，某像素预测值为 0.8，表示模型给出的目标类别分数较高；这个值未经校准，不能直接称为“该位置有癌症的概率”。

研究最终形成四类成果：可复现的数据处理与训练程序、四组对照和重复实验结果、逐病例统计与可视化分析、据此撰写的论文及实验报告。当前阶段先形成可执行的设计，不提前填写性能数字。

### 1.1 与相近任务的边界

| 任务 | 回答的问题 | 本课题是否作为主要目标 |
| --- | --- | --- |
| 图像分类 | 这张图属于什么类别？ | 否；良恶性信息可以用于数据描述与探索分析 |
| 目标检测 | 目标大致在哪里，框出什么位置？ | 否 |
| 语义分割 | 哪些像素属于目标区域？ | 是 |
| 临床诊断 | 患者是否患病，应该怎样处理？ | 否 |

“病灶”不等于“癌症”。数据中的良性和恶性病变都可以是需要分割的对象。因此，论文使用“病灶分割效果”，不能把 Dice 解释为癌症诊断准确率，也不能由本数据集上的表现推导临床可用性。

## 2. 应用统计学生需要掌握的最少医学知识

理解本研究无需先学完整的临床医学课程，但需要掌握以下概念，避免误读标签。

| 概念 | 实际含义 | 在研究中的用途或边界 |
| --- | --- | --- |
| 乳腺超声 | 使用声波成像的一种检查方式 | 理解为什么图像与普通照片不同 |
| 病灶与周围组织 | 标注的目标区域及其背景 | 明确二分类分割的目标 |
| 斑点噪声 | 超声成像中常见的颗粒状纹理 | 理解目标和背景容易混淆的原因 |
| 低回声等描述 | 病灶相对于周围组织的声学表现 | 阅读病例表时认识术语；无需自行判断 |
| 边缘特征 | 对目标边缘形态的专业描述 | 只能按数据集原有字段与定义进行分组 |
| 良性、恶性、正常 | 数据集中的诊断或病例类别 | 用于描述样本构成，不能混同于掩码像素类别 |
| 专家掩码 | 人工标注的参考区域 | 作为模型学习与评价的参考，并非无误差的绝对真值 |

“边缘形态不规则”“边缘不清晰”和“图像质量差”是不同概念。若没有可靠的图像质量标签，本研究不应凭主观印象新增“模糊组”并开展医学解释。可以展示典型图像并作描述性讨论，但需要说明选择规则与主观性。

正常图像没有目标区域。正常图像与有病灶图像的评价逻辑不同：前者关注是否错误地画出了病灶，后者关注区域重合和遗漏。本项目拟将正常病例作为独立误检探索集，不用于训练、阈值选择或主分割指标平均；空掩码处理按实验协议执行，不能用正常病例的满分重合度抬高主结果。

## 3. 数据集为什么适合，限制在哪里

导师指定 BrEaST，TCIA 集合名称为 Breast-Lesions-USG。原始数据论文描述了 256 名患者的 256 张图像和相应标注，其中包含 154 例良性、98 例恶性、4 例正常图像。最终纳入数量必须经过实际文件核对后确定，不能只按论文总数直接生成实验表格。[2][3]

它适合本课题，是因为图像规模适中，已经提供专家标注和病例信息，能够开展标准分割模型实验，也便于进行逐病例检查。但适合本科研究，不意味着足以证明方法具备临床泛化能力。

需要优先解决五个数据问题：

1. **图像与掩码一一对应。** 用病例表确认对应关系，不按文件排列顺序自动配对。
2. **目标与其他对象分开。** 核对目标肿瘤标注、其他结构标注以及可能存在的多个标注文件，形成明确的合并或排除规则。
3. **以患者为划分单位。** 当前数据按论文描述是一人一图；程序仍保留患者编号，以防后续补充数据引入同患者多图。
4. **检查图像中的文字、标尺和边缘信息。** 记录这些信息是否可能影响模型。如果决定裁剪，需要统一规则并同步变换掩码，不能逐张主观裁剪。
5. **保留原始资料。** 原图、原始标注和下载说明保持只读；数据处理生成新文件，不覆盖原文件。

局限应从开题阶段就明确：样本量较小、病例构成有限、单个公开数据集上的结果未必适用于其他设备或人群、专家标注也可能存在边界不确定性。正常病例仅 4 例，适合单独展示误检探索，不能支撑稳定的筛查结论。

## 4. U-Net 的工作原理：从直觉到实现

可以把 U-Net 理解为先理解“是什么”，再恢复“在哪里”的图像处理网络。

- **编码器**通过卷积提取局部纹理，通过下采样逐步扩大感受范围。图像的空间尺寸减小，但特征表达更丰富。
- **瓶颈层**在更粗的尺度上整合上下文信息。
- **解码器**逐步恢复空间分辨率，输出每个位置的类别信息。
- **跳跃连接**把编码器相应尺度的细节送给解码器，帮助定位目标边界。
- **输出层**产生单通道的病灶分数，经过 Sigmoid 得到 0 到 1 的逐像素输出。[1]

本课题以 256×256 图像为输入，输出同样空间尺寸的概率图。“二维”意味着逐张二维图像处理，不涉及三维体积重建。输入通道数应由数据核验确定：若文件虽为 RGB 存储但实质是灰度，可采用统一的灰度方案；若确有彩色内容，应先明确处理规则，不能直接假定三个通道完全相同。

“标准 U-Net”也要具体化：记录每一层通道数、卷积方式、上采样方式、激活函数和初始化设置。为设备内存降低起始通道数时，应在论文中说明这是统一采用的实现配置，不能隐去与原论文的差别。所有对照组使用同一结构。

### 4.1 为什么比较损失函数

BCE（二元交叉熵）逐像素评价预测与标注的差异。病灶通常只占图像的一部分，背景像素较多，训练可能受到类别不平衡影响。

Dice 损失直接围绕预测与参考区域的重合程度构造目标，对区域重合有不同于 BCE 的侧重。BCE＋Dice 联合损失尝试同时利用两者，但最终是否更好，需要通过对照实验判断。训练时使用可微的软 Dice，评价时通常使用阈值化之后的硬 Dice，两者不能混写。

### 4.2 为什么比较数据增强

数据增强在训练时对图像与掩码同步变换，以模拟有限范围的位置或角度变化。它增加了训练输入的变化，但没有创造新的独立患者，不能把增强后的图像数当作新增样本量。

增强强度应适度。过强旋转、平移或变形可能破坏图像结构，移出病灶，或造成不自然的外观。增强只用于训练集；验证集和测试集使用固定预处理，确保成绩可比较。

## 5. 将题目收敛成可回答的研究问题

| 编号 | 研究问题 | 预设分析方向 | 允许出现的结论 |
| --- | --- | --- | --- |
| RQ1 | BCE＋Dice 相比 BCE 是否改善分割？ | 在相同增强条件下进行配对比较 | 改善、无明确差异，或某些病例更差 |
| RQ2 | 适度增强是否改善分割与稳定性？ | 在相同损失条件下比较均值、分布和种子波动 | 整体有益、影响不明确，或增强不适合当前数据 |
| RQ3 | 两种因素的作用是否相互依赖？ | 查看增强效果是否随损失函数改变 | 探索性交互现象，不夸大统计功效 |
| RQ4 | 哪些病例更容易失败？ | 病灶相对面积、已有边缘标签与病例级指标 | 描述相关关系与典型错误，避免因果解释 |

可以提出“联合损失有望改善区域重合”“适度增强有望减少过拟合”等工作假设，但不能把假设写成既定事实。主要终点、配对比较、分组标准和模型选择规则应在查看测试结果前确定。

具体协议预设 D−A（联合损失且增强，相比 BCE 且不增强）为主要比较，用于评价组合训练策略。RQ1、RQ2 通过 B−A、D−C、C−A、D−B 等次要比较解释单个因素，不能把 D−A 的全部变化归因于某一个因素。RQ3 与 RQ4 属于探索性问题。

## 6. 应用统计学的价值体现在哪里

本课题的统计价值在于把一次模型训练扩展成可信的对照研究。

**第一，实验设计可比。** 四个实验组构成“损失函数×数据增强”的 2×2 设计。在网络结构、患者划分及主要训练设置一致的条件下，分析两种因素对应的效果差异。

**第二，分清随机性。** 测试病例之间的差异、同一训练设置在不同随机种子下的差异、不同数据划分带来的差异，是三个来源。固定划分下的 3 个种子只能部分反映训练随机性，不能声称已经充分评价数据划分稳定性。

**第三，使用正确的统计单位。** 同一病例被多个模型预测属于配对或重复测量；3 次预测不会变成 3 名新患者。像素也不是独立的患者样本。统计表应保留病例编号、方案编号和种子，避免混合计算。

**第四，同时关注差异大小与不确定性。** 不只报告谁最高，还报告提高了多少、病例间有多大波动、差异是否集中在少数病例。置信区间如采用患者重抽样，需说明其条件于当前数据划分和已训练模型，并不涵盖全部训练与数据来源的不确定性。

**第五，克制解释。** 若小病灶 Dice 较低，原因可能包括像素离散化、面积小导致相同边界误差占比更大等；不能直接推断某种疾病更难诊断。样本少的亚组主要作描述，避免频繁检验后挑选显著结果。

## 8. 合理的贡献与研究困难

本科论文可以形成的贡献是：围绕明确数据集建立规范的分割研究流程，系统比较两类训练因素，结合病例层面统计解释适用性与局限。能否称为方法创新，要以实际工作与文献检索为依据。不能预先使用“首次”“显著优于现有方法”或“达到临床水平”。

主要困难及处理方向如下：

| 困难 | 处理方向 |
| --- | --- |
| 样本少，模型容易过拟合 | 适度增强、早停、限制调参、记录验证曲线 |
| 小病灶缩放后细节损失 | 检查缩放前后面积及掩码有效性，单独报告相关情况 |
| 阈值影响结果 | 只在验证集按统一规则选择，测试集固定使用 |
| 训练耗时与设备兼容 | Mac 本地先做短训练测速；明确 CPU/Metal 环境；需要时再转移完整训练 |
| 结果差异不大 | 检查实现是否公平，报告差异与区间，不为追求高分改动测试规则 |
| 医学解释有限 | 依照数据标签、原始论文与导师指导解释，不自行作临床推断 |
