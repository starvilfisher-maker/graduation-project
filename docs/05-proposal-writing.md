# 开题报告、文献综述与论文写作指南

> 文件性质：章节设计与写作说明。它不是正式开题报告正文，不包含已完成的研究结果。用户已开始推进完整毕业论文；本文保留开题材料的要求，并给出完整论文结构，以便让实验产出与最终写作对应。逐步操作从[论文执行与学习路线](09-guided-thesis-roadmap.md)开始。

当前仓库交付的是 Markdown 研究材料，并非已按学校 Word 模板排版的最终开题文件。原模板仅作为只读参考，不上传到公开仓库。具体实验规则与参数以[数据协议](02-data-protocol.md)和[实验协议](03-experiment-and-statistics.md)为准。

已提供的 Word 是开题报告模板，不能自动当作正式毕业论文的排版模板。正式论文的封面、章节格式、字数和参考文献格式，待学院正式论文要求明确后再排版；这不妨碍先开展实验和撰写内容草稿。

## 1. 如何使用学校模板

根据用户提供的模板说明，开题报告不少于 3000 字，文献综述不少于 3000 字；外文翻译中文汉字 3000 字以上，并附外文原稿。开题报告与文献综述合用的参考文献至少 15 篇，其中外文至少 2 篇、近三年至少 5 篇。正式提交前仍需对照学院最终要求核验计数口径和格式。

模板为结构与格式依据，其中示例题目、预填日期及示例内容不属于本课题事实。近三年的范围按实际提交年度和学院口径核对；2026 年提交可先围绕 2024—2026 年检索，不能为了凑数量保留不相关文献。

本指南不提供日历或时间安排。正式模板如果必须填写“进度计划”，由用户按学院和导师要求单独补齐。原始模板不随本仓库公开上传。

正式开题文字应主要使用“拟采用”“计划比较”“将评价”。只有真实完成并留有记录的工作，才可以写成“已完成”。可行性分析不能把尚未获得的实验成绩当作依据。

## 2. 开题报告各部分具体怎么写

### 2.1 选题背景与研究意义

建议形成三个层次：先说明乳腺超声图像中目标区域分割的作用，再说明噪声、边界与形态差异带来的技术困难，最后引出小样本条件下 U-Net 训练策略比较的研究价值。

这一部分不宜写成大篇幅疾病科普。涉及发病率、死亡率、临床诊疗或检查优势等医学事实时，必须有可核验的权威来源；若不是论证必需，可以减少此类数字。把“分割为形态分析提供基础”写清楚即可，不能直接扩展为“本研究提高临床诊断水平”。

研究意义可分为方法应用与统计评价两个方面：前者是构建规范分割流程，后者是在统一条件下分析效果差异、随机波动和病例异质性。把“能够完成什么”与“最终可能有什么价值”分开。

### 2.2 国内外研究现状

围绕问题组织文献，而非逐篇写作者介绍：

1. 超声病灶分割面临的成像与标注问题。
2. 传统分割方法及其对复杂纹理、模糊边界的限制。
3. U-Net 的结构与医学图像分割中的应用。
4. 损失函数与类别不平衡、区域重合的关系。
5. 数据增强在小样本学习中的作用及不适当增强的风险。
6. 数据划分、评价指标、重复实验与报告规范。

每个主题末尾回答“已有研究说明什么、仍有哪些局限、这与本课题有什么关系”。不能用“很多研究很少关注”之类笼统判断制造研究空白。若尚未完成全面检索，使用“本课题拟在统一条件下比较”即可。

不同论文可能使用不同数据集、预处理、测试划分和评价方法，数值不能直接横向排名。引用高分结果时必须交代实验条件；不满足公平比较的文献，只作为方法或背景依据。

### 2.3 研究目标与研究内容

目标写成可检验的产出，而非泛泛的“提高准确率”：

- 建立病例清单和检查规则，确保图像与目标掩码正确对应。
- 实现统一预处理、患者划分与二维 U-Net 基线。
- 完成损失函数和数据增强的四组对照，以及各组至少 3 个随机种子的重复实验。
- 对测试病例逐例计算 Dice、IoU，报告病例分布与训练波动。
- 分析小病灶、已有边缘特征以及漏分割和过分割案例。
- 保存可运行程序、配置、结果和必要说明，形成论文与实验报告。

“研究内容”应解释各项做什么及相互关系；详细参数放到“研究方法”。避免同一段内容在多个章节重复粘贴。

### 2.4 研究方法与技术路线

建议按下面的完整链条写作，并画成技术路线图：

```text
获取原始数据与说明
        ↓
病例表核对 → 图像/掩码质检 → 明确纳入与排除规则
        ↓
固定患者划分，保存训练/验证/测试名单
        ↓
统一预处理；仅训练集实施同步增强
        ↓
同一 U-Net，四种训练方案，各至少 3 个种子
        ↓
验证集选择模型/必要参数/阈值，冻结规则
        ↓
测试集逐病例评价，保存预测及轮廓叠加
        ↓
配对比较、波动分析、病例亚组与失败分析
        ↓
形成论文结论、局限及可复现材料
```

这一节需要回答容易被追问的细节：患者如何分组、哪些图像进入主实验、缩放方法为何不同、图像和掩码如何同步增强、随机种子改变什么、早停依据是什么、阈值在哪里确定、指标先按病例计算还是先把像素合并。

参数尚未确定时可给出有限候选范围及选择原则，但不要在开题报告中列出无限调参清单。对照实验的公平规则应明确，例如所有组共用数据划分、结构、训练上限和模型选择标准。

### 2.5 统计分析方案

需要区分三层内容：

| 层次 | 写作内容 |
| --- | --- |
| 主要分析 | 逐病例 Dice 为主、IoU 为辅；预设 D−A 为主要配对比较，评价组合训练策略，并计算患者层面的配对 Bootstrap 区间 |
| 稳定性分析 | 各随机种子下的平均成绩及波动；说明固定划分重复实验的适用范围 |
| 探索性分析 | 指标与病灶相对面积、已有边缘标签的关系，以及正常图像误检 |

统计方法的复杂程度要与样本量和数据结构相匹配。本方案已预设描述性统计、配对差值、图形检查及 5000 次患者重抽样的 Bootstrap 置信区间；先按病例对三个种子的指标求平均，再保留方案间配对关系进行重抽样。区间条件于当前划分与已训练模型，不覆盖全部训练或外部人群的不确定性。其余方案差异作次要探索；若以后增加正式假设检验，应在查看测试结果前声明方法与多重比较处理，不能从大量比较中仅汇报显著结果。

本方案将正常图像保留为独立误检探索集，应分开写评价指标与空掩码规则，不参与训练、阈值选择或主分割均值。由于样本仅少数例，报告每例预测前景面积等信息通常比给出一个看似精确的“特异度”更容易解释。

### 2.6 关键问题、可行性与预期成果

关键问题写具体：小样本过拟合、掩码对应与缩放、小目标信息损失、方案比较的公平性、随机波动与结果复现。

可行性依据包括公开可获取的数据和专家标注、成熟的 U-Net 思路、已有 Python 基础，以及可用于调试的本机设备。MacBook Air M5、24GB 内存可用于起步验证；训练速度和 TensorFlow/Metal 兼容性仍要实测，不能在未测试时写“设备完全满足全部实验”。

预期成果可以写“形成完整实验流程、完成多组比较、识别典型失败情形”。不预设“Dice 达到 0.9”“显著优于所有方法”等具体数字或优越性。贡献可以是规范应用与系统实证比较，无需虚构结构创新。

## 3. 文献综述怎样做到有内容

文献综述的作用是支撑研究设计，不是把开题背景扩写一遍。建议围绕“任务与数据—模型—训练策略—评价—问题归纳”的逻辑构成全文。

### 3.1 建立文献证据表

每篇文献至少整理以下字段：

| 字段 | 为什么记录 |
| --- | --- |
| 标题、作者、年份、DOI/链接 | 保证来源可查，便于统一引用 |
| 研究任务与数据集 | 判断是否真正与超声病灶分割相关 |
| 样本量与患者划分方法 | 检查可比性与潜在数据泄漏 |
| 模型、损失与增强 | 提取与本课题有关的设计依据 |
| 主要指标及汇总单位 | 避免混淆逐病例平均与总体像素汇总 |
| 重复实验、外部验证 | 了解结果稳定性与泛化证据 |
| 局限及可借鉴之处 | 为本课题的选择提供明确理由 |

检索可组合关键词：`breast ultrasound lesion segmentation`、`U-Net`、`Dice loss`、`binary cross entropy`、`data augmentation`、`BrEaST`。中文检索可使用“乳腺超声 病灶分割”“U-Net 损失函数”“医学图像分割 数据增强”。

优先读取原始论文和数据说明；综述用于建立地图，再回到关键原文核验。仅有摘要或无法访问全文时，在笔记中说明证据范围，不编造实验设置。经典 U-Net 文献虽较早，仍有必要保留；近年文献用于补充当前进展，不需要让全部引用都变成近年论文。

### 3.2 外文翻译选材

首选候选是 U-Net 原始论文或 BrEaST 数据集论文，分别帮助理解网络结构和本课题的数据基础。最终选择应确认学院是否允许整篇或节选、原文篇幅是否能支撑所需中文汉字数，并避免使用未经核实的网络译文。

翻译需统一专业术语，例如 segmentation 译为“分割”、mask 译为“掩码”、lesion 译为“病灶”、ground truth 可译为“参考标注”并视原文语境处理。保留公式、图表编号和引文对应关系；不能为了通顺而更改原文的适用条件或将不确定表达翻译成肯定结论。

仓库仅记录来源链接、阅读笔记和选材说明。公开发布原文 PDF 或长篇译文前，应核对原文许可及适用条件；学校提交附件与 GitHub 公开发布是不同用途。

## 4. 完整论文结构与对应实验材料

| 章节 | 核心内容 | 写作所需证据 |
| --- | --- | --- |
| 第 1 章 绪论 | 背景、问题、意义、研究内容 | 核验后的文献与明确研究边界 |
| 第 2 章 理论与相关研究 | 超声分割、U-Net、损失函数、指标 | 原始论文、公式与实现对应说明 |
| 第 3 章 数据与方法 | 数据来源、质检、划分、预处理、模型和统计方案 | 数据字典、配置、流程图 |
| 第 4 章 实验结果 | 四组对照、重复实验、病例分布、亚组和可视化 | 真实训练记录、逐病例指标及图像 |
| 第 5 章 讨论 | 结果解释、失败原因、与文献的谨慎对照、局限 | 结果与文献共同支撑的解释 |
| 第 6 章 结论与展望 | 回答研究问题，说明后续可做什么 | 已被实验支持的结论 |

章节名称以学校最终论文规范为准。方法章节写“如何做”，结果章节写“观察到什么”，讨论章节写“可能意味着什么”；三者不要混在一起。

### 4.1 建议准备的图表

- 数据纳入流程图：从原始病例到各分析集，注明真实排除原因。
- 数据构成表：总体及训练、验证、测试集病例数与必要构成。
- 图像及参考掩码示例：解释模型输入与输出，不用于主观选择最好成绩。
- U-Net 结构图和四组实验配置表。
- 训练与验证曲线：反映收敛、早停和过拟合情况。
- 各组各种子的结果表，以及最终汇总表。
- 病例 Dice/IoU 分布图与配对差值图。
- 病灶相对面积与 Dice 的散点图，以及必要的亚组描述表。
- 成功、一般、失败病例的轮廓叠加图，附病例选择规则。
- 正常图像误检表（如纳入）与限制说明。

图表须可追溯到保存的数据。不要手动改图中的数字，不要把示意图写成真实预测结果。对实验尚未进行的开题报告，可以放技术路线图、结构示意图；数据示例只有实际核验后才能使用。

## 5. 开题答辩容易被问到的问题

| 问题 | 回答要点 |
| --- | --- |
| 为什么应用统计学做这个题目？ | 核心包含对照实验、配对评价、随机波动、异质性和不确定性分析，模型是研究工具 |
| 为什么选择 U-Net？ | 它适合像素级医学图像分割，结构明确且便于建立可复现基线；不宣称它是当前最先进模型 |
| 为什么数据只有几百例还可以做？ | 适合有限范围的方法应用研究，采用患者划分、增强和早停；承认样本量对精度和泛化的限制 |
| 为什么不用准确率？ | 背景像素占比高可能使准确率产生误导，Dice/IoU 更直接反映区域重合 |
| 3 个随机种子够吗？ | 满足导师最低要求，用于初步检查训练波动；不能据此证明全部随机性已被充分覆盖 |
| 联合损失没有提高怎么办？ | 如实报告，并检查公平性、病例分布和误差来源；研究不以必须得到正向结果为前提 |
| 创新在哪里？ | 重点是统一条件下的系统比较、统计解释和可复现流程；未完成文献核验前不宣称方法首创 |
| 能用于临床吗？ | 当前属于研究性离线实验，缺少外部验证与临床验证，无法作出临床可用结论 |

## 6. 正式提交前的内容检查

逐项检查：研究问题是否与实验一一对应；导师要求是否覆盖；所有数据数字是否有来源；计划与已完成工作是否区分；文献是否真实且正文确有引用；主要终点、测试规则和空掩码规则是否明确；图表是否可追溯；局限是否与实际设计一致。

报告中不填写虚构成绩，不把数据增强当作扩大独立样本量，不把单数据集实验称为临床验证，不因缺乏新网络结构而堆砌无关模块。清楚、可执行、能够检验，是当前开题材料最重要的质量标准。
